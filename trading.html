Connect Your Deriv Account to XeroAI

To connect your Deriv account, you will need two credentials: your Deriv App ID and your API Token. Follow the steps below carefully.

1Create Your Deriv App ID

  1. Sign in to your Deriv account.
  2. Enter XeroAI Trading Bot as the app name.
  3. Keep Markup at 0%.
  4. Enter https://xeroai.live as your website URL.
  5. Accept the Deriv terms and conditions.
  6. Click Create application.
  7. Copy and securely save your App ID.
Create Deriv App ID

2Create Your Deriv API Token

  1. Once your App ID has been created, open the token page.
  2. Enter XeroAI Trading Bot as the token name.
  3. Select your preferred expiration date.
  4. Select the Trade authorization scope.
  5. Click Create Token.
  6. Copy and securely save your API Token.
Create Deriv API Token

3Enter Your Credentials in XeroAI

You should now have:

  • App ID — your Deriv application ID
  • API Token — your Deriv personal access token

Enter both credentials in the Connect Your Deriv Account fields above, then click Connect Deriv.

Security Notice: Never share your API Token publicly or with anyone you do not trust. Your API Token provides access to your Deriv account according to the permissions you selected.

Need Help?

If you are unable to create your App ID or API Token, or you encounter an error during the process, please contact Deriv Support before proceeding. XeroAI Support can also help you connect your credentials after they have been created.
